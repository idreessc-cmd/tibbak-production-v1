# Tibbak Release Notes — Version 0.1.0-mvp

## 🚀 Release Overview

**Tibbak Version 0.1.0-mvp** is a presentation-ready release candidate designed to demonstrate end-to-end healthcare marketplace operations in the MENA region.

---

## ✨ Key Features & Capabilities

- **Bilingual Experience**: Full Arabic (`/ar`) and English (`/en`) routes with RTL/LTR layouts.
- **Provider Search & Directory**: Organic search engine with specialty, city, and service filters.
- **Tiered Lead Entitlements**: Free Tier lead limiting (3 leads maximum) with Professional/VIP unlimited lead access.
- **Organic Ranking Independence**: Quality scores and organic search ordering remain strictly independent of paid commercial subscriptions or sponsored campaign activations.
- **Provider Operational Governance**: Operational status enforcement (`active`, `suspended`, `inactive`, `archived`) removing unavailable providers from search and blocking appointment mutations.
- **Atomic Booking Service**: `completeDemoBooking` service coordinating case creation, appointment booking, and patient session establishment.
- **Privacy-by-Design DTOs**: `ProviderCaseSummary`, `AdminCaseOperationalSummary`, and `ProviderAttachmentMetadata` enforce strict data minimization.
- **Production Audit Clean**: Production dependency audit contains **0 Critical, 0 High, 0 Moderate, 0 Low** vulnerabilities.
